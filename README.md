### [Secure Purchase Order System](https://github.com/malykasardar)

Cryptographic Python module securing end-to-end purchase order workflows in a Flask web app. Implements hybrid RSA-2048/AES-256-GCM encryption, RSA-PSS digital signatures, role-based access control, CSRF protection, and rate limiting hardened to NIST standards.

### [Autonomous Vehicle Stack — Ontario Tech Research](https://github.com/malykasardar)

Modular ROS-based autonomous vehicle stack deployed across two platforms (e-scooter and e-go-kart). Built real-time LiDAR object detection with hardware-level e-stop authority, GPS navigation with vision-based lane following, and a pluggable vision adapter pattern for hot-swappable models.

### [Elevator Optimization — ML + Monte Carlo Simulation](https://github.com/malykasardar)

Discrete-event simulation modelling 24 elevators across 16 decks using SimPy. Trained a Random Forest regressor to predict deck-level passenger demand (MAE: 2.07). ML-enhanced controller achieved a statistically significant 9.13% reduction in wait time vs baseline across 100 paired simulations (p<0.0001).

Python-based system health monitoring and alerting service for Linux environments. Covers log monitoring, memory tracking, and process control.

Bug-tracking system with a FastAPI backend and PostgreSQL, built around RESTful API patterns.

### [Job Search Automation Agent](https://github.com/malykasardar)
